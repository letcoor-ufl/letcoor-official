# LETCOOR

**Decentralized coordination for connected teams.**

LETCOOR is a private coordination and communication application designed for teams operating in the field.

It provides a decentralized way for groups to communicate, coordinate and exchange information directly between devices without relying entirely on a traditional centralized communication infrastructure.

LETCOOR is designed for situations where teams need reliable, structured and privacy-conscious coordination.

## Use Cases

LETCOOR can be used for:

- Airsoft
- Outdoor team games
- Training exercises
- Large group activities
- Event organization
- Field coordination
- Recreational tactical simulations
- Team-based outdoor activities

The project is designed as a general-purpose coordination platform and is not tied to any particular organization or activity.

## Decentralized Communication

LETCOOR uses a peer-to-peer and local-first architecture.

Depending on network availability and device capabilities, LETCOOR can communicate using multiple connection methods, including:

- Direct Internet peer-to-peer connections
- Local network connections
- Wi-Fi Direct
- Bluetooth proximity connections
- Multi-hop communication between authorized peers

Devices can therefore exchange information without requiring a traditional central server containing user communications.

The network is designed to automatically use available communication paths and allow information to propagate between authorized members of a group.

## Team Coordination

LETCOOR provides tools for organizing groups in the field.

Features include:

- Groups and teams
- Group and team roles
- Team leaders

## Privacy

LETCOOR is designed around a local-first and privacy-conscious architecture.

Key principles include:

- No central database containing user groups and communications
- Communications between devices are encrypted
- Data is primarily stored locally on participating devices
- Information is only shared with authorized members
- Location sharing is optional
- Location information is intended to be temporary
- Group and team access is controlled cryptographically
- Knowing the network address of another device does not automatically grant access to its data

LETCOOR does not require a central service to store the communication history of its users.

## Hybrid Peer-to-Peer Network

LETCOOR can use different physical communication methods within the same logical network.

For example, one device may communicate with another using Wi-Fi Direct while another part of the network uses Bluetooth, LAN or an Internet connection.

Information can then be relayed between authorized peers.

A permanent direct connection between every device in a group is not required.

This allows LETCOOR to build a distributed communication network while keeping the number of direct connections per device limited.
